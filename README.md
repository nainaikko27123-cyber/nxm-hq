# NXM HQ 🎤

A macOS management app for running a fictional entertainment company: idol groups, members, a dance studio and more.

## Features
- **Groups & members:** create idol groups and edit member profiles and cards
- **Dance studio:** manage dance groups and their details
- **Relationships:** track how members get along
- **Awards & company overview:** see the whole company at a glance
- **Fan surveys** and a live status bar
- Themed accent colors and smooth page transitions

## Built with
Swift · SwiftUI · macOS, organized into Models, Views, State and Persistence layers

## Run it
Open `IdolStudio.xcodeproj` in Xcode and press **Run**.
